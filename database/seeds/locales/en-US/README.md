# en-US locale seeds

Active-locale display content for the SDKWork Plugins catalog.

- `001_plugin_categories_display.sql` writes the registry taxonomy labels
  (`ai_plugin_category.name` and its locale map) for the categories the
  dsh-market registry publishes.
- `002_plugin_catalog_display.sql` writes each catalog record's display name
  and description for this locale.

The files are generated by `tools/import_dsh_market_catalog.mjs`; regenerate
them with the catalog rather than editing them by hand. Their checksums are
recorded in `seed.manifest.json#localeSets` and in
`seeds/dsh-market-catalog.snapshot.json`.
