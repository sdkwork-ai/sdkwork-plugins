# sdkwork-plugins specs

Local application/component contracts and narrowing rules. Machine contracts
live here; README/docs are discovery, not standards.

- `component.spec.json`: component ownership and dependency contract.
- `iam.module.manifest.json`: IAM permission catalog materialized by the IAM
  module registry (`sdkwork-iam`), authoritative for `plugins.*` codes.
- `topology.spec.json`: deployment topology declaration.
