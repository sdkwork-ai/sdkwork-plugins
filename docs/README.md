# sdkwork-plugins docs

Discovery documentation for the SDKWork Plugins application root: AI capability
plugin registry (plugin categories + managed plugins), Rust APIs, generated SDK
families, and a PC admin client.

- Product domain: `ai_plugin_*` tables, `/app/v3/api/plugin*` and
  `/backend/v3/api/plugin*` surfaces.
- Admin console integration: the `sdkwork-cloudrouter` admin console mounts the
  backend-api surface and consumes `@sdkwork/plugins-pc-admin`.
